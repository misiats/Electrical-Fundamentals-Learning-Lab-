# 🔋 Навчальна лабораторія з основ електротехніки

Інтерактивний застосунок на Streamlit для студентів перших курсів фізичних
та електронних спеціальностей. Він охоплює напругу, силу струму, опір,
потужність, енергію, змінний і постійний струм, закон Ома, закони Кірхгофа
та з’єднання резисторів.

## 📖 Огляд проєкту

Лабораторія доповнює навчальні модулі з логічних елементів та електронних
компонентів. У ній розглянуто 10 основних понять і 6 законів та співвідношень.
До понять додано пояснення, схеми й, де доречно, інтерактивні калькулятори.

Застосунок працює локально за допомогою `streamlit`, `pandas` і `matplotlib`.
Для роботи йому достатньо встановлених залежностей.

## ✨ Розділи

- **🏠 Вступ.** Аналогія з водою в трубі допомагає зрозуміти зв’язок між
  напругою, силою струму й опором.
- **🔎 Основні поняття.** Картки з поясненнями, SVG-схемами, одиницями
  вимірювання, формулами, прикладами застосування та примітками з безпеки.
- **📐 Закони та співвідношення.** Довідкова таблиця з фільтром за
  категоріями та картки основних законів.
- **🎛️ Інтерактивний симулятор.** Калькулятори закону Ома, потужності,
  енергії, загального опору й змінної напруги, а також перевірка законів Кірхгофа.
- **🔬 Практичні застосування.** Приклади з побутової проводки, акумуляторів,
  освітлення, електромереж, електроніки та електромобілів.
- **🧪 Лабораторія діагностики.** П’ять ситуацій із варіантами відповіді
  та поясненням після вибору.
- **📝 Тест.** Десять запитань із трьома варіантами відповіді. Після
  завершення можна переглянути результат і пройти тест повторно.

## 🎯 Навчальні цілі

1. Пояснювати напругу, силу струму, опір, потужність та енергію простими словами.
2. Застосовувати закон Ома й формулу потужності для розв’язання задач.
3. Обчислювати загальний опір послідовно та паралельно з’єднаних резисторів.
4. Застосовувати закони Кірхгофа до простих кіл.
5. Розрізняти змінний і постійний струм та перераховувати амплітудне й діюче
   значення синусоїдальної напруги.
6. Розпізнавати ці закономірності в реальних електричних системах.
7. Визначати ймовірні причини простих несправностей у колах.

## ⚙️ Встановлення й запуск

```bash
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

Відкрийте адресу, яку Streamlit покаже в терміналі. Зазвичай це
`http://localhost:8501`.

## 🗂️ Структура проєкту

- `app.py` містить розрахунки, навчальні матеріали, SVG-схеми та інтерфейс.
- `requirements.txt` містить список залежностей Python.
- `README.md` описує проєкт і його запуск.

Українські назви понять зберігаються в полі `label` словника `CONCEPTS`,
а назви категорій — у `CATEGORY_LABELS`. Ідентифікатори понять і категорій
використовуються у фільтрах, симуляторі та генераторі схем. Тексти законів,
тесту й завдань з діагностики містяться в `LAWS`, `QUIZ` і `TROUBLESHOOTING`.
Підписи елементів інтерфейсу розміщені біля відповідних викликів Streamlit
і Matplotlib.

## 🎓 Використання в навчанні

Лабораторія підходить для занять, самостійної роботи або підготовки до
практичних робіт з фізики й електроніки. Її можна пройти перед вивченням
електронних компонентів.

## ⚠️ Безпека

- Проводьте роботи з побутовою електромережею лише під наглядом
  кваліфікованого фахівця.
- У розділах про напругу, види струму, провідники та ізоляцію є окремі
  попередження про небезпеку.
- Калькулятори використовують навчальні моделі. У реальних колах враховуйте
  допуски компонентів і запас за допустимим навантаженням.
